# NilaiKarya - Sistem Monitoring Absensi & Akademik Siswa

## 📌 Deskripsi Singkat
NilaiKarya adalah sistem informasi terpadu berbasis web yang diformulasikan untuk memfasilitasi pencatatan absensi harian dan perkembangan evaluasi belajar siswa. Proyek ini menyelesaikan masalah dokumentasi rekapitulasi manual di kelas serta meniti jembatan transparansi informasi perkembangan akademik harian yang mudah dinavigasi secara langsung antara Guru dan Orang Tua.

## 🛠 Tech Stack
- **Language:** PHP / JavaScript / HTML / CSS
- **Database:** MySQL (Prepared Statements via PDO / MySQLi)
- **Framework/Tools:** Native PHP / Asynchronous JavaScript API / Responsive UI CSS

## ✨ Fitur Utama
- **Pencatatan Absensi Cepat Guru:** Portal khusus bagi pengajar untuk mengelola absensi dan rekapitulasi data kehadiran siswa dengan alur pengiriman data API yang cepat, tepat, dan anti-duplikasi.
- **Portal Pemantauan Orang Tua:** Kemudahan akses langsung bagi para orang tua guna memonitor jejak rekap nilai tugas, ulangan harian, serta absensi perkembangan anak secara komprehensif.
- **Integrasi Asynchronous API:** Sinkronisasi interaktif intervensi data kehadiran secara langsung menggunakan request AJAX/Fetch tanpa perlu *page reloads*, menguntungkan efektivitas jam kerja di kelas.
